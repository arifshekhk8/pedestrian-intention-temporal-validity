# Issue 2 — Leakage Re-Audit on Clean (crossing_point-anchored) Sequences

**Verdict: ✅ CLEAN**

Generated by `01_leakage_audit.py`. Ground truth = PIE per-frame `cross` attribute (values: `not-crossing` / `crossing` / `crossing-irrelevant`), re-parsed from the annotation XML because the original `01_parse_annotations.py` kept only `action` and dropped `cross`.

## Setup

- Sequences audited: **4906** (crossers 1648, non-crossers 3258)
- Observation window: **16 frames** ending at `anchor_frame`
- Build TTE: **event-relative, TTE in [30,60] frames anchored at crossing_point (sequences_clean/ — see 02_build_sequences_clean.py)**
- Leakage = ≥1 frame inside the observation window with `cross == "crossing"` (pedestrian already crossing while observed)

## 1. Window leakage

| Group | N | sequences with ≥1 crossing frame in window | % |
|---|---|---|---|
| Crossers (label=1) | 1648 | 0 | 0.0% |
| Non-crossers (label=0) | 3258 | 0 | 0.0% |
| **All** | 4906 | 0 | 0.0% |

- Crossers with the **entire 16-frame window already crossing** (all frames `crossing`): **0** (0.0% of crossers) — pure detection, not prediction.
- Crossers with a **genuinely clean window** (0 crossing frames): **1648** (100.0% of crossers).
- Crossers whose **anchor frame itself** is already `crossing`: **0** (0.0% of crossers)
- Crossers with a labelled crossing onset: 1648; of those, onset at/before window end (`anchor−onset ≥ 0`): **12** (0.7%)

- `anchor − onset` (frames): median -44, mean -43.5, min -60, max 609. Positive ⇒ window reaches into the crossing (leakage); negative ⇒ genuine look-ahead prediction.

## 2. Static-shortcut test (anchor-frame bbox geometry)

Can crosser vs non-crosser be separated by the *static* bounding box at the last observed frame, with no temporal info? Mann–Whitney U (two-sided); rank-biserial |r|: 0=none, 0.1 small, 0.3 medium, 0.5 large.

| Feature | crosser median | non-crosser median | p | rank-biserial |
|---|---|---|---|---|
| bbox_bottom_y | 838.3 | 829.4 | 2.86e-07 | +0.090 |
| bbox_height | 143.3 | 108.2 | 1.63e-33 | +0.211 |
| bbox_xcenter | 1050.7 | 1211.4 | 3.06e-01 | -0.018 |
| bbox_area | 6544.6 | 3756.1 | 1.46e-45 | +0.247 |

See `figures/anchor_bbox_shortcut.png`.

## 3. Interpretation

- **No window leakage.** No observation window contains a `crossing` frame, so the model never observes the crossing itself — the task is genuine ahead-of-time prediction, not detection. This is the sentence to put in the paper's Experimental Setup.
- **No strong static shortcut:** anchor-frame bbox geometry alone does not separate the classes (all |rank-biserial| < 0.3), so the signal is in the temporal dynamics, not a static position giveaway.
