## Defects found and fixed

### 1. Ten IDD scripts could not run — stale library path

`experiments/05_cross_dataset/idd/*.py` all did `sys.path.insert(0, str(FOLDER / "src"))`. The reorg
that produced this repository moved that directory to `idd/lib/`, and the path was never updated, so
every one of the ten failed with `ModuleNotFoundError: No module named 'iddped_parser'`. Changed to
`HERE / "lib"`. All ten now import.

### 2. `src/metrics.py` could not be imported at all

It loaded its two model classes from `pipeline/03_bilstm_model.py` and
`transformer/phase1_setup/00_transformer_model.py` — paths in the source project. Neither exists
here, so the module raised `FileNotFoundError` on import. This mattered because `README.md` lists it
as a core module and `PROTOCOL.md` cites `src/metrics.py::best_threshold` as the definition of the
threshold rule. Repointed at this repository's own `src/model_bilstm_legacy.py` and
`src/model_transformer.py`, which hold the same classes. Verified: imports, builds both models, and
`load_splits()` returns the expected `(2178, 16, 5)`.

Its docstring also still called it `00_common.py` and described it as part of the F1 program. Rewritten,
with a scope note stating that nothing in the Tier 1 path imports it.

### 3. Eleven more scripts pointed at source-project paths

`cluster_bootstrap.py`, `loso_cv.py`, `bootstrap_ci.py`, `gt_vs_detector.py`, `inference_latency.py`,
`f1_first_comparison.py`, `final_test_eval.py`, `gru_compare.py`, `rnn_compare.py`,
`run_ow_extension.py`, `live_demo.py` and `eval_parity_check.py` each loaded a helper module from a
directory that does not exist here. Every one had a local equivalent:

| was | is now |
|---|---|
| `f1_optimization/00_common.py`, `HERE/00_common.py` | `src/metrics.py` |
| `pipeline/03_bilstm_model.py`, `06b_local_verify_seed42.py` | `src/model_bilstm_legacy.py` |
| `journal_prep/issue12_unified_pipeline/12_unified_engine.py` | `src/engine.py` |

In `demo/live_demo.py` the model import also sat six lines *above* the definition of `ROOT` it used,
so it would have raised `NameError` even with the path corrected. Reordered.

### 4. `REPRODUCE.md` Tier 3 instructed the reader to download a release that does not exist

The documented first step was `gh release download v1.0`. There are **zero releases** on the
repository. The scripts it then told the reader to run — `cluster_bootstrap.py` and
`transformer_vs_bilstm.py` — could not have run in any case.

Tier 3 is now titled "archival: not runnable here" and states both reasons: the checkpoints and
`probs_cache/` tensors are absent, and five scripts read source files that were never copied. It
points the reader at the Tier 1b scripts, which are the fully reproducible replacement, and at the
`results/` table that backs each claim. `LIMITATIONS.md` §6 carried the same false promise and was
corrected to match.

### 5. `LIMITATIONS.md` §1 contradicted itself twelve lines apart

The table said positives sit **158–741** frames before track end; the paragraph below said
**88–6606**. Recomputed from `data/pie_clean/` and `pie_annotations.pkl`: min 88, median 287,
max 6606. The table was wrong and is corrected. (Negatives, 32–62 median 46, were right.)

### 6. The phase-matched control undermines C6, and no document said so

`MATCHED_COMPARISON.md`, `CONTRIBUTIONS.md` C6 and `README.md` all stated "the families do not tie"
as an unconditional finding. Under the phase-matched control **0 of 18** family contrasts survive,
against **7 of the same 18** under the standard sampling. The claim is conditional on the sampling
and all three documents now say so, with the caveat that a failure to resolve is not equivalence
(the strongest remaining contrast misses at p = 0.0032 against a 0.00278 threshold).

This was the most consequential inconsistency found: a reader could have quoted the architecture
ranking from `README.md` without ever learning that the repository's own control removes it.

### 7. `REPRODUCE.md` mixed the two ego-speed conventions in one line

It quoted "+0.0126 to +0.1477", taking the low end from the bootstrap-tested ensemble delta and the
high end from the 5-seed mean. `CONTRIBUTIONS.md` C4b explicitly forbids this — "quote one convention
or the other — do not mix them, as an earlier version of this line did". Changed to the 5-seed mean
range, +0.0156 to +0.1477, and labelled.

### 8. Machine-written reports quoted source-project paths and absent figures

The two leakage reports cited `01_leakage_audit.py`, `01_parse_annotations.py`,
`leakage_per_sequence.csv`, `cross_state_map.pkl` and three `figures/*.png` files. The scripts have
different names here, the CSV ships under a different name, and neither the cache nor any figure was
copied. Same pattern in the JAAD reports, `idd_results/TABLES.md` and `model_comparison.md`. All
corrected to the paths that exist; where a file genuinely is not here, the report now says so instead
of linking into nothing.
