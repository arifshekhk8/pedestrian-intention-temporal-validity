# IDD-PeD cross-dataset validation — comparison tables

Generated by `experiments/05_cross_dataset/idd/07_analysis.py`. Every number traces to `expA_zero_shot.json` (this folder) / `expB_independent.json` (this folder) and the audits.

**Metric hierarchy** is the supervisor's F1 → accuracy → AUC for *in-domain* work. For the **cross-domain** numbers we lead with **AUC / PR-AUC**, which are threshold-free and therefore comparable across two datasets with very different base rates (PIE test 32.5 % positive, IDD-PeD test 7.1 %); F1 and accuracy follow at a fixed, never-re-tuned threshold. This rule was set in the source project's cross-dataset plan.

On IDD-PeD a 7.1 % base rate makes accuracy near-meaningless (do-nothing scores 0.929) and puts the bar for a *useful* F1 at 0.133. **Zero-shot F1 lands at 0.129–0.131 — at or below that bar.** This is stated plainly rather than presented as a modest score.
