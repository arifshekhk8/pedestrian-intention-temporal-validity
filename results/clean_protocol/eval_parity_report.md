# Issue 2 follow-up — Evaluation-Parity Check (clean baseline)

**Question (reviewer):** our clean test AUC 0.913 with only bbox+speed *beats* multimodal PIE baselines (PCPA 0.86, GTransPDM 0.87, PIP-Net 0.90). Is our evaluation easier than theirs? Two suspects: (a) per-window AUC over overlapping correlated windows; (b) a laxer minimum-track-length filter.

Generated by `experiments/01_leakage/eval_parity_check.py` on the clean baseline checkpoint, test split = set03.

## 1. Per-window vs per-pedestrian AUC

The crossing label is constant per pedestrian, so the correlation-free metric is per-pedestrian. 50% overlap gives each ped several near-identical windows; if a few easy peds dominated the window count, per-window AUC would be optimistic.

- unique test pedestrians: **541** from **2094** windows (windows/ped: min 1, median 4, mean 3.87, max 4 — nearly uniform)
- per-ped pos rate 0.329 vs per-window 0.325 (matched)

| metric | AUC |
|---|---|
| per-WINDOW (final.json headline) | 0.9131 |
| per-PEDESTRIAN, mean prob | 0.9143 |
| per-PEDESTRIAN, last window (min TTE) | 0.9266 |
| per-PEDESTRIAN, max prob | 0.8886 |

**window − ped(mean) gap = -0.0012** → negligible. Overlap is NOT inflating the number; per-window and per-pedestrian agree.

## 2. Minimum-track-length parity

We exclude tracks shorter than obs+TTE_min = 46 frames; the canonical `min_track_size` is 75. With stride 8 and TTE∈[30,60], a track ≥76 frames yields the full 4 windows, so window-count splits test peds into benchmark-comparable (≥4 windows, track ≥76) vs short tracks only we admit.

- benchmark-comparable peds (track ≥76): **504** (pos 0.325)
- short tracks we additionally admit (46–75): **37** (pos 0.378)

| subset | per-ped AUC |
|---|---|
| benchmark filter only (track ≥76) | 0.9194 |
| all peds (our laxer filter) | 0.9143 |
| short tracks only (46–75) | 0.8634 |

Our extra short tracks are **harder**, not easier — restricting to the benchmark filter would *raise* AUC, so the laxer filter does not inflate the headline.

## 3. Verdict

**Evaluation parity holds.** The 0.913 clean AUC is robust to (a) the correlated-windows critique (per-ped 0.914) and (b) the min-track-length difference (benchmark-filter subset 0.919). The result therefore reflects genuine predictive signal in bbox motion + ego-speed, not an easier evaluation — directionally consistent with the Occlusion-Aware Diffusion paper's bbox+ego-only results (0.93–0.95 — NOT protocol-comparable per Issue 3: occluded-only, ~1-frame TTE; modality precedent only). This is the number and framing to carry into the Issue 3 baseline comparison.

Remaining documented deviation (state in Experimental Setup, not a confound): we sample at 0.5 overlap (the PIE config's trajectory value; 0.3 is its action default) — shown above to be immaterial since per-ped ≈ per-window.
